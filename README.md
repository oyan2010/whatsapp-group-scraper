# WhatsApp Lead Extractor & Group Scraper 📱⚡

An automated lead-generation suite designed to extract, deduplicate, and export contact numbers from WhatsApp groups with a modern desktop UI.

---

## 🌟 Features

- **Automated WhatsApp Web Scraper**: Interacts with WhatsApp Web to safely parse and extract participant numbers from joined groups.
- **Deduplication Engine**: Filters out existing contacts, normalizes international dialing codes, and cleans duplicates.
- **Desktop GUI**: Clean interface to select groups, start extractions, and monitor progress live.
- **Multi-Format Export**: Export contact lists directly to Excel (`.xlsx`) or CSV format for CRM imports.

---

## 🛠️ Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/oyan2010/whatsapp-group-scraper.git
   cd whatsapp-group-scraper
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Launch the Application**:
   ```bash
   python gui_app.py
   ```
